# dog-shop

**Status:** Active · **Type:** Family shopping-list PWA (Cloudflare Pages + Worker/D1) · **Owner:** Greg (family) · **Lane:** personal / family

Dog Shop is the Doggett family's shared shopping-list PWA — installs to any phone's home screen, everyone adds to one master list, Beth submits the cart to Walmart. Frontend is `index.html` (Cloudflare Pages, auto-deploys on push to main via the CF Pages Git integration); the API + data live in `worker/` (Cloudflare Worker + D1). Operating contract: [`CLAUDE.md`](CLAUDE.md). Answers to the vault `Canon.md` + `CLAUDE.md` (master). Intended to connect into the orchestration system later (vault memory `project-dog-shop-orchestration`).
